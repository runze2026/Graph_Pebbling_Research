\section{Computational Results}\label{sec:computational}

The computations in this section provide an independent validation of the
main formula and illustrate the structure of the extremal configurations.
In particular, we verify that the predicted value
\[
\pi(T(3,s_1,s_2))=2^d+1
\]
holds for several small instances, and that the observed failing
configurations at size $2^d$ coincide with the critical configuration $D^*$
used in the lower-bound proof.

Nothing in this section is used in the proofs of Section~\ref{sec:proofs}.
We exhaustively solved four instances with
$d\in\{3,4,5\}$ (Table~\ref{tab:results});
$T(3,2,3)$ with $d=6$ was not completed.
The exhaustive search data and computational logs are available in
\path{data/computational_results.json} and the accompanying scripts described
in Section~\ref{sec:data-availability}.


\subsection{Method}


For each $G=T(3,s_1,s_2)$ we built an exhaustive solver
(\texttt{pebbling\_solver.py}) with two reductions:
leaf-target pruning (justified in general by Corollary~\ref{cor:pruning},
and confirmed directly for these four instances by
Table~\ref{tab:leaf-verify}, which lists every vertex) and quotienting by
$\operatorname{Aut}(G)$.

The solver uses the \emph{pebbling state graph}, whose vertices are pebble
configurations and whose directed edges represent legal pebbling moves between
configurations. Reachability of a target vertex is then determined by a
breadth-first search on this state graph.

Starting from a diameter-based lower bound on $S$, the program enumerates
$S$-pebble multisets and returns the least value of $S$ for which every leaf
target is reachable from every configuration.

A \emph{worst failing configuration} is an unsolvable configuration at the
largest tested threshold below the pebbling number; in the tables below this
means a configuration with exactly $S=2^d$ pebbles that fails to reach the
specified target.

\subsection{Computational performance}


The longest completed run is $T(3,1,3)$, with

\[
\pi(G)=33
\]

at $S=33$.

At $S=32$, the solver examined

\[
2,760,681
\]

isomorphism-reduced configurations.

The exhaustive search output is available in
\path{data/computational_results.json}.

The instance $T(3,2,3)$ with $d=6$ was not completed:
at $S=64$ there are approximately

\[
1.3\times10^9
\]

raw placements of $64$ pebbles on seven vertices.


\subsection{Computational validation of the weight function}
\label{sec:wf-computational}


For $d\le4$, every configuration satisfying

\[
w(p)>w(1_G)=2^d
\]

was checked and found solvable for each of the six leaf-target pairs.

For $d=5$, we verified only the normalization identity

\[
w(1_G)=2^5=32 .
\]

The detailed computational records are provided in
Appendix~\ref{sec:appendix-computational}.


The computations above provide evidence for the structure of the extremal
configurations and motivate the general proof developed in the following
section. The next section establishes the exact formula analytically through
the matching lower and upper bounds.
